# BioseqDB examples

Runnable examples accompanying the [BioseqDB blog](https://bioseqdb.com/blog/).

- [Butterfly genome comparison](butterfies_alignments/): retrieve NCBI sequence intervals with SQL, align them in BioseqDB, and draw the results with SQLAlchemy and Plotly.
- [Sequence workflows with BioseqDB and SeqKit](seqkit_workflows/): import UCSC sequences with SQL, compare everyday sequence operations, and plot length, nucleotide composition and GC content.
